# X Writing Skill

## Purpose

Express ideas on X. Optimize for clarity, engagement, and format. This skill handles **how** to say it, not **what** to think.

## When to Load

Load this skill when:
- ✅ Research and narrative are complete
- ✅ Task is expression, not thinking
- ✅ Formatting for X engagement
- ✅ Applying writing style guidelines

Do NOT load when:
- ❌ Gathering data (use market-research)
- ❌ Validating claims (use source-verification)
- ❌ Determining what to say (use narrative-analysis)
- ❌ Algorithm questions (use x-algorithm)

## Inputs

### Required
- Verified claims from source-verification **OR**
- Narrative analysis output with recommended content

### Load These References
- writing-style.md (voice, tone, formatting)
- account-positioning.md (who we are, target audience)

## Evidence Window

**NARRATIVE: No time restriction**

This skill uses:
- Writing style guidelines (evergreen)
- Account positioning (stable)
- Content pillars (stable)

**CURRENT: Only for time-sensitive posts**

Examples:
- "Post about today's ETF flows" → Use current data
- "Comment on Fed statement" → Use today's statement

## Workflow

### Step 1: Review Input

From narrative-analysis or source-verification:

```
Input Type: Narrative Analysis Output

Verified Claims:
- IBIT +2,847 BTC (+$180M) on 2026-09-04
- Macro liquidity improving (yields down, DXY down)
- M2 growth positive since July 2026

Narrative Position:
- Advances "macro leads, ETFs lag" thesis
- Contrarian angle: ETFs are noise, macro is signal

Recommended Content:
- Post type: Contrarian take + data
- Thesis: "Everyone's watching ETF flows. They're looking at the wrong metric."
```

### Step 2: Load Writing Style

From writing-style.md:

```
Voice Attributes:
- Analytical over emotional
- Confident over arrogant
- Educational over preachy
- Humble when wrong

Formatting:
- Hook: First 120 characters (scroll-stop)
- Body: 1-3 sentences with data
- Visual: Chart, screenshot, or diagram
- Length: 180-260 characters (leaves room for engagement)

Tone:
✅ "Here's what the data shows..."
❌ "Trust me, I know what's happening..."
```

### Step 3: Determine Post Type

From account-positioning.md content pillars:

| Pillar | Format | Example |
|--------|--------|---------|
| Data Drop | Single post + chart | "IBIT +$180M yesterday. Biggest inflow in 2 weeks."
| Contrarian Take | Single post + visual | "Everyone's watching ETFs. Wrong metric."
| Narrative Analysis | Thread (3-7 tweets) | "Two views on this rally. Here's the data for each..."
| Educational | Thread (5-10 tweets) | "How I think about macro liquidity and BTC..."
| Catalyst Watch | Single post + list | "Watching 3 catalysts this week: CPI, Fed, NFP."

**This Task:** Contrarian Take + Data

### Step 4: Draft Hook

Hook formulas (from writing-style.md):

**Contrarian Hook:**
```
"Everyone's watching ETF flows. They're looking at the wrong metric."
```

**Data Hook:**
```
"IBIT added $180M yesterday. But that's not what's driving BTC."
```

**Question Hook:**
```
"Why is everyone focused on ETF flows? The real driver is [X]."
```

**Selected:** Contrarian Hook (aligns with narrative thesis)

### Step 5: Draft Body

Structure:
```
[Hook: First 120 chars]
[Body: 1-2 sentences with data]
[Visual: Chart or diagram]
[Optional: CTA or punchline]
```

**Draft 1:**
```
Everyone's watching ETF flows. They're looking at the wrong metric.

IBIT added $180M yesterday. But M2 growth turned positive in July - that's the real driver.

ETF flows are coincident. Macro liquidity leads by 2-4 weeks.

[Chart: M2 vs. BTC price, 2020-2026]
```

**Character Count:** 247 characters (good, leaves room for engagement)

### Step 6: Apply Style Guidelines

From writing-style.md checklist:

- [x] Hook is specific and scroll-stopping
- [x] Main point clear in first 2 sentences
- [x] Data is verified (from source-verification)
- [x] Visual adds value (M2 vs. BTC chart)
- [x] Under 280 characters
- [x] Analytical tone (not emotional)
- [x] No jargon without explanation

### Step 7: Final Review

**Against Account Positioning:**

- [x] Matches voice (analytical, confident, educational)

- [x] Contrarian angle clear

## Output Format

```markdown
## X Writing: ETF Flows vs. Macro
## Date: 2026-09-05
## Post Type: Contrarian Take + Data

### Draft

Everyone's watching ETF flows. They're looking at the wrong metric.

IBIT added $180M yesterday. But M2 growth turned positive in July - that's the real driver.

ETF flows are coincident. Macro liquidity leads by 2-4 weeks.

[Chart: M2 vs. BTC price, 2020-2026]

### Visual Recommendation

**Chart:** M2 money supply (y/y % change) vs. BTC price
- Timeframe: 2020-2026
- Highlight: July 2026 M2 inflection point
- Source: FRED (M2), exchange data (BTC)
- Annotation: "M2 leads by 4-8 weeks"

### Engagement Optimization

**Best Time to Post:** 8-10 AM EST (market open, high engagement)

**Reply Strategy:**
- Respond to all comments in first hour
- Pin reply with chart source links
- Engage with contrarian perspectives (builds discussion)

**Hashtags:** #Bitcoin #ETF (2 max, relevant)

**Thread Option:** If engagement is high, follow up with:
- Tweet 2: Historical M2 vs. BTC correlation
- Tweet 3: Why ETF flows are lagging indicator
- Tweet 4: What to watch next (macro data this week)

### Confidence: High

**Reason:**
- All data verified against primary sources
- Aligns with account's narrative thesis
- Matches writing style guidelines
- Clear contrarian angle with evidence

### Variations (A/B Testing)

**Variation A (More Direct):**
```
ETF flows are noise. Macro liquidity is signal.

M2 turned positive in July. BTC rallying now. Not a coincidence.

IBIT added $180M yesterday, but that's coincident, not causal.

[Same chart]
```

**Variation B (Question Hook):**
```
Why is everyone focused on ETF flows?

The real driver: M2 growth turned positive in July.

ETFs are coincident. Macro leads by 2-4 weeks.

IBIT added $180M yesterday. But liquidity setup matters more.

[Same chart]
```

### What NOT to Post

❌ "ETFs don't matter at all" (false, they're one factor)
❌ "BTC to $70K next week" (price target without evidence)
❌ "Trust me, I know macro better than everyone" (arrogant tone)
❌ Long explanation of M2 calculation (overcomplicates, loses audience)
```

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Loading before research is complete | Use market-research → source-verification → narrative-analysis first |
| Overcomplicating the message | One clear takeaway per post |
| Ignoring writing-style.md | Always apply voice, tone, formatting rules |
| No visual recommendation | Every post should have visual suggestion |
| Too long (>280 chars without thread) | Trim or convert to thread |
| Emotional or arrogant tone | Keep it analytical and humble |
