# Algorithm Evals

## Purpose

Evaluate X post performance against algorithm benchmarks.

## Metrics Tracked

| Metric | Target | Weight | Notes |
|--------|--------|--------|-------|
| Impression-to-Engagement Rate | >3% | 30% | (Replies + Reposts + Likes) / Impressions |
| Reply Rate | >0.5% | 20% | Replies / Impressions |
| Repost Rate | >0.3% | 20% | Reposts / Impressions |
| Profile Clicks | >1% | 15% | Profile clicks / Impressions |
| Follows from Post | >0.1% | 15% | New followers / Impressions |

## Scoring

- **A (90-100)**: Exceeds targets across most metrics
- **B (80-89)**: Meets or slightly exceeds targets
- **C (70-79)**: Meets some targets, gaps in others
- **D (60-69)**: Below targets, needs optimization
- **F (<60)**: Significantly underperforms

## Example Eval

**Post:** "Bitcoin ETFs had -$412M outflows yesterday..."
**Date:** 2026-09-04
**Impressions:** 45,200

**Score:** A- (91/100)

**Breakdown:**
- Impression-to-Engagement: 30/30 (4.2% vs 3% target)
- Reply Rate: 20/20 (0.7% vs 0.5% target)
- Repost Rate: 20/20 (0.5% vs 0.3% target)
- Profile Clicks: 13/15 (0.9% vs 1% target, close)
- Follows from Post: 8/15 (0.08% vs 0.1% target, slightly low)

**Insights:**
- Strong engagement velocity in first hour
- High reply quality (thoughtful questions)
- Profile clicks good but could improve CTA
- Consider stronger follow-worthy hook next time
