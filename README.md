## Workflow

### Daily (30-45 min)

1. **Morning Research Briefing** (15 min)
   - Scan ETF flows, macro data, crypto on-chain
   - Identify 1-2 key data points
   - Note any narrative shifts

2. **Content Creation** (15-20 min)
   - Draft 1-2 posts using x-writing guidelines
   - Add visual (chart, screenshot)
   - Verify all claims against source registry

3. **Publish & Engage** (throughout day)
   - Post at optimal times (8-10 AM, 6-9 PM)
   - Reply to comments within 1 hour
   - Track engagement metrics

### Weekly (1-2 hours)

1. **Narrative Analysis** (30 min)
   - Map competing narratives on key topics
   - Assess which are gaining/losing momentum
   - Identify contrarian angles

2. **Source Registry Update** (15 min)
   - Add new credible sources discovered
   - Remove sources that lost credibility
   - Note any methodology changes

3. **Performance Review** (30 min)
   - Evaluate top/bottom 5 posts of the week
   - Identify patterns (topics, formats, hooks)
   - Adjust content strategy accordingly

### Monthly (2-3 hours)

1. **Positioning Audit** (30 min)
   - Review account positioning statement
   - Assess if content matches positioning
   - Adjust pillars or focus if needed

2. **Skill Refinement** (1 hour)
   - Update skill docs based on learnings
   - Add examples from top-performing content
   - Refine checklists and frameworks

3. **Evals Archive Review** (1 hour)
   - Review research, narrative, writing, algorithm evals
   - Identify improvement areas
   - Set goals for next month

## Quality Standards

### Research

- All claims backed by Tier 1 or Tier 2 sources
- Numbers verified against primary data
- At least 2 competing narratives identified
- Contrarian take is specific and falsifiable

### Writing

- Hook is specific and scroll-stopping
- Main point clear in first 2 sentences
- Visual adds value (not decorative)
- Under 280 characters (or thread is numbered)

### Publishing

- Post at optimal times (8-10 AM, 6-9 PM local)
- Reply to comments within 1 hour
- Track engagement metrics weekly
- Iterate based on performance data
